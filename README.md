# Remojii Academy API

Go modular monolith: one API (`cmd/api`) on Postgres.

## Quick start

```sh
make migrate-up   # apply SQL migrations (the API refuses to start on a stale schema)
make run          # API on :8080; .env sets APP_ENV=dev (enables learner-token / editor-token / admin-token, seeded as users)
make test         # TEST_DATABASE_URL=postgres://... also runs the migration tests on a throwaway database
```

```sh
curl localhost:8080/healthz
curl -H 'Authorization: Bearer admin-token' -X POST localhost:8080/v1/chapters
```

`APP_ENV` (dev|staging|prod) is required, with no default, so a missing value can never enable dev auth.
Request logs carry `user_id` and `role`: admin writes have no audit table, so these are the record.

## Layout

```
cmd/api
api/              openapi.yaml, embedded; served at /openapi.yaml, Swagger UI at /docs
internal/
  app/            router wiring + permission-matrix test
  httpx/          HTTP errors, middleware, OpenAPI/Swagger handlers
  identity/       roles, auth middleware, TokenResolver, RequireChapter 402 hook (AllowAllChapters stub until P6)   <- real
  content/ learning/ gamification/ introtest/ platformadmin/
                  http.go = every route from endpoints.md with role guards, returning 501
  db/             pgx pool, WithTx/Conn, goose migration runner
  <module>/queries/*.sql   hand-written SQL  ->  <module>/store (generated by sqlc, do not edit)
migrations/       versioned goose SQL files (embedded); also the schema sqlc reads
```

## Data layer

pgx + [sqlc](https://sqlc.dev) + [goose](https://github.com/pressly/goose). No ORM.

- Schema change: `make migrate-new name=add_foo`, edit the file in `migrations/`, `make migrate-up`.
  Always write the `-- +goose Down` too. Never edit a migration that has shipped.
- Query change: edit `internal/<module>/queries/*.sql`, run `make sqlc`, commit the generated code.
- Stores take a `db.DBTX`; use `db.WithTx` + `db.Conn(ctx, pool)` to run several stores in one transaction.
- Cross-module foreign keys live only in `migrations/`; modules never import each other.

Module rules: a module touches only its own tables; cross-module calls go
through Go interfaces; handlers stay thin.
